
# Maze Generator & Solver

A terminal-based maze game developed using Python as part
of the CS213 Introduction to Python Programming course
at IIIT Raichur.

## Overview

The application generates random mazes and provides
interactive gameplay, automatic maze solving, and
performance tracking.

## Features

- Random maze generation using Depth-First Search (DFS)
- Multiple maze difficulty levels
- Player navigation using W, A, S, D
- Automatic shortest-path solving using BFS
- Completion time and move tracking
- Score calculation and persistent leaderboard

## Technologies

- Python
- Random
- Time
- JSON
- Collections

## Project Structure

- `main.py` - Application entry point
- `maze.py` - Maze generation and representation
- `player.py` - Player movement
- `solver.py` - BFS maze solver
- `scoreboard.py` - Score storage and leaderboard

## Running the Project

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project directory:

```bash
cd maze-generator-solver
```

Run the application:

```bash
python main.py
```
